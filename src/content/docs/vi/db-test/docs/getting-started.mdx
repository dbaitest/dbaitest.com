Về công cụ dòng lệnh, xem [CLI](/vi/db-test/docs/cli/).

## Yêu cầu

- **Docker** phải đang chạy. Harness khởi động container thật thông qua [Testcontainers](https://github.com/testcontainers/testcontainers-dotnet).
- **.NET 8 trở lên.** Các package có sẵn asset `net8.0` và `net10.0`. .NET 8 và 9 dùng asset `net8.0`, .NET 10 trở lên dùng asset `net10.0`.

:::note
CLI tự roll forward, nên chạy được trên bất kỳ runtime nào ở trên mà máy bạn đã cài.
:::

:::caution
Thiếu `[assembly: DoNotParallelize]`, các test thay đổi hình dạng của object dùng chung sẽ làm hỏng lẫn nhau. Container dùng chung đòi hỏi bộ test chạy tuần tự.
:::

Nếu không gọi `DisposeAllAsync()`, resource reaper của Testcontainers sẽ xóa container khi test host thoát.

## 5. Chạy thử

{/* not in upstream: illustrative */}

```bash
dotnet test
```

Test đầu tiên của mỗi engine khởi động container và áp dụng schema. Các test sau trong cùng lần chạy dùng lại container đó.

Nếu Docker không chạy, test đầu tiên fail với lỗi thật và mọi test sau fail ngay với cùng lỗi đó, thay vì mỗi test tự chờ container của nó đến khi timeout.
