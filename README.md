# dbaitest.com

Source of [dbaitest.com](https://dbaitest.com): the hub and the documentation for the
dbaitest projects, in English and Vietnamese. Built with Astro Starlight, served as static
assets by a Cloudflare Worker, deployed from `main` by GitHub Actions.

| Project | Repository | Site |
|---|---|---|
| db-test | [dbaitest/db-test](https://github.com/dbaitest/db-test) | [dbaitest.com/db-test](https://dbaitest.com/db-test/) · [docs](https://dbaitest.com/db-test/docs/) |

Each project's docs are built from its repository at the release pinned in
[`projects.json`](projects.json).

Local development, the checks, adding a project, bumping a release and rolling back
production: see [CONTRIBUTING.md](CONTRIBUTING.md). Security issues: [SECURITY.md](SECURITY.md).
